"Make a collection of API and start testing the one by one" 


1. Get All Products

GET		http://localhost:8000/products

2. Get Product By ID

GET		http://localhost:8000/products/1

3. Get Invalid Product

GET		http://localhost:8000/products/999

4. Create Product

POST		http://localhost:8000/products

Body	

{
    "name": "Test Product",
    "sku": "TP001",
    "category_id": 1,
    "price": 100,
    "quantity": 50,
    "low_stock_threshold": 10
}
